# Welcome to BlogApp

This is a full-stack blog application built with Next.js App Router, Drizzle ORM, and PostgreSQL.

## Features

- **Blog Management**: Browse, create, like, and filter blogs.
- **User Authentication**: Secure credentials-based authentication with NextAuth.js.
- **Reading Lists**: Track your reading habits with read/unread statuses.
- **API Token**: Generate personal tokens for external programmatic API access.
